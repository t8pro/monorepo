# Upload-Free Thank You

Follow-up screen rendered at `app/upload-free/thank-you/page.tsx` after a successful free trial submission.

## Structure

- `index.tsx` – static content with highlight cards and social prompt.
- `styles.module.scss` – presentation and responsive layout rules.

## Key Behaviours

- Card copy reassures users about turnaround time and encourages inbox monitoring.
- Social call-to-action links to Instagram in a new tab.

## Extending

- Update the `infoCards` array in `index.tsx` to adjust messaging.
- Add new engagement CTAs (newsletter, portfolio, etc.) by extending the info grid.
